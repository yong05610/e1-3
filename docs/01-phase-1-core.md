# Phase 1 — 핵심 MAC 계산과 판정

## 개발팀 지시서

먼저 docs/00-PRD-and-design.md와 루트의 TASK.md를 읽으세요. 이 요청으로 승인된 범위는 Phase 1뿐입니다. 다른 phase 기능이나 보너스 작업은 구현하지 마세요.

### 목적

Mini NPU Simulator에서 재사용할 MAC 계산과 epsilon 기반 판정의 핵심 함수를 구현합니다.

### 이번 단계 범위

- 프로젝트에 main.py가 없으면 새로 만들고, 있으면 기존 내용을 먼저 살펴 변경 범위를 보존합니다.
- mac(matrix_a, matrix_b)는 같은 크기의 2차원 행렬을 받아 같은 위치의 값끼리 곱한 뒤 모두 더한 점수를 반환합니다.
- MAC은 Python 반복문으로 직접 구현합니다. NumPy 등 외부 라이브러리는 사용하지 않습니다.
- classify(score_a, score_b, epsilon=1e-9)는 A 승리, B 승리, 동점을 구분합니다.
- abs(score_a - score_b) < epsilon이면 동점으로 처리합니다. 동점 기준을 소스에 설명합니다.
- 빈 행렬·비정사각 행렬·행렬 크기 불일치에서 함수가 어떻게 반응할지 구현하고 명확한 오류를 제공합니다. 정책이 모호하거나 기존 코드와 충돌하면 임의로 정하지 말고 PM에게 질문합니다.
- 함수의 입력값, 반환값, 오류 조건과 동점 기준을 docstring 또는 짧은 주석으로 설명합니다.

### 이번 단계에서 하지 말 것

- 메뉴, 대화형 사용자 입력, 사용자 입력 모드
- data.json 로드, 정규화, 사례별 PASS/FAIL
- 성능표, 전체 결과 요약, README 작성
- 클래스 도입, 외부 라이브러리, 보너스 기능
- 승인되지 않은 파일 삭제·이름 변경·대규모 재구성

### 완료 확인 기준

- 미션 예시 3×3 십자가 입력과 십자가 필터의 MAC 점수가 5인지 확인합니다.
- 같은 입력과 X 필터의 MAC 점수가 1인지 확인합니다.
- 같은 점수와 epsilon 미만의 차이가 동점인지 확인합니다.
- epsilon보다 큰 차이에서 높은 점수 쪽을 판정하는지 확인합니다.
- 반복문 기반 구현이며 외부 수치 라이브러리가 없는지 확인합니다.
- 자동 테스트 파일이나 테스트 프레임워크를 추가하지 않습니다. 위 기준을 확인한 실행 명령과 실제 출력을 보고서에 남깁니다.
