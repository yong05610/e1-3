# Phase 4 완료 보고서 — 크기별 성능 분석

## 1. 변경·추가 파일과 성능 함수

- `main.py` — JSON 모드 뒤에 전체 크기 성능 표를 출력하도록 연결
- `docs/reports/phase-4-report.md` — Phase 4 확인 결과 기록
- 기존 `benchmark_mac(matrix_a, matrix_b, repetitions=10)`을 재사용했습니다. 각 실행에서 `perf_counter()`로 `mac()` 반복 호출 구간만 재고 평균 ms를 반환합니다.
- 새 `run_performance_analysis(data, repetitions=10)`은 벤치마크 행렬을 측정 전에 준비하고, 크기별 시간과 N²를 표로 출력합니다.

## 2. 벤치마크 입력과 반복 횟수

- 3×3은 지시서가 정한 미션 예시 십자가 및 X 행렬을 사용했습니다.
- 5×5, 13×13, 25×25는 `data.json`에서 읽어 검증한 각 크기의 `Cross` 필터와 `X` 필터를 사용했습니다.
- 각 크기에서 `benchmark_mac()`을 기본 10회 반복합니다. 반복 횟수는 `run_performance_analysis()` 인수의 기본값으로 관리하며, 사용자 입력이나 파일 I/O는 측정 구간에 들어가지 않습니다.
- `benchmark_mac()`은 시작 시각을 저장한 뒤 반복문에서 `mac()`만 호출하고, 반복 종료 후 경과 시간을 계산합니다. 출력은 측정 함수가 끝난 뒤 이뤄집니다.

## 3. 제공 데이터 실행 결과

실행 명령:

```powershell
$env:PYTHONIOENCODING='utf-8'; @('2') | python -B main.py
```

실제 성능 표:

| 크기(N×N) | 평균 시간(ms, 10회) | 연산 횟수(N²) |
|---:|---:|---:|
| 3×3 | 0.007050 | 9 |
| 5×5 | 0.014710 | 25 |
| 13×13 | 0.074250 | 169 |
| 25×25 | 0.325150 | 625 |

같은 실행의 결과 요약은 총 테스트 6, 통과 3, 실패 3이었습니다. 실패 케이스는 `size_5_1`, `size_13_2`, `size_25_1`이며, 모두 epsilon 기준 동점으로 `UNDECIDED` 판정이 된 사례입니다. Phase 3의 판정과 총계가 유지됐습니다.

## 4. I/O 제외 확인

`benchmark_mac()`의 `perf_counter()` 시작/종료 사이에는 `for` 반복과 `mac(matrix_a, matrix_b)` 호출만 있습니다. 행렬 로드·검증, 성능표 출력, 사례 출력은 측정 전후에 수행합니다. JSON 결과를 먼저 처리한 뒤 표를 출력하므로 파일 읽기와 사례 I/O 시간도 포함되지 않습니다.

## 5. 사용자 입력 모드 3×3 회귀 확인

십자가 필터 A, X 필터 B, X 패턴 입력으로 다시 실행했습니다. 실제 주요 출력:

```text
A 점수: 1.0
B 점수: 5.0
연산 시간(평균/10회): A 0.007210 ms, B 0.006830 ms
판정: B
```

사용자 모드의 A/B별 3×3 평균 시간 표시가 유지됐습니다.

## 6. 측정값 변동

측정값은 현재 실행 환경에서 얻은 실제 값이며 코드에 고정하지 않았습니다. 동일 데이터로 재실행했을 때도 예를 들어 3×3은 0.016350 ms, 5×5는 0.016620 ms, 13×13은 0.086390 ms, 25×25는 0.412770 ms로 달라졌습니다. 실행 시점의 시스템 부하와 측정 환경에 따라 차이가 날 수 있습니다.
